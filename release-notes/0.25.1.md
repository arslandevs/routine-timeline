Maintenance release for the Obsidian community directory checks. No behaviour changes.

- Fixed inline styles now go through Obsidian's `setCssStyles` instead of assigning `element.style` directly.
- Opening the view uses `setActiveLeaf` instead of `revealLeaf`, so nothing needs a newer Obsidian than the declared 1.4.0.
- Releases are built by GitHub Actions with artifact attestations for `main.js`, `styles.css` and `manifest.json`, and no longer include an extra zip.
- Smaller cleanups: `builtin-modules` replaced with `node:module`, unused variables removed, unhandled promises in event handlers fixed, `instanceof TFile` instead of a cast.
- Added `npm run lint` with the same rule set the directory scan uses.
